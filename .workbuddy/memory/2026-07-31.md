## pnpm publish 报错排查（ERR_PNPM_PACKAGE_VERSION_NOT_FOUND）

- 仓库是 pnpm monorepo，根 package.json 为 `private: true` 且无 `version` 字段（正常）。
- 用户在根目录直接执行 `pnpm publish`，pnpm 走内置 publish 命令试图发布根包 → 找不到 version 报错。
- 正确做法：用项目已定义的 script `pnpm run publish`（或 `pnpm run publish:force` 加 --no-git-checks），会通过 `pnpm -r --filter` 只发布 `@gantt/core` 与 `@gantt/vue-gantt`。
- 关键陷阱：`publish` 是 pnpm 内置命令，`pnpm publish` 不会运行同名 script，必须带 `run`。
- 子包均配 `prepublishOnly: pnpm build`，发布前自动构建；scope 包配 `publishConfig.access: public`。

### year/quarter 视图日期标签看不到（columnWidths 单位语义 bug）

- 用户反馈：切到 "年/季度" 后 timeline 完全看不到日期文本
- 排查路径：`packages/core/src/services/computeTimeScale.ts:23` `width = diffDays × columnWidth`，columnWidth 语义是 **每天像素**，不是每列像素
- demo 配置把 "目标每列宽度" 直接传成 columnWidth：`quarter: 82` → 91 天 × 82 = **7462px/列**，label 居中在 3731px 处，绝大多数 scrollLeft 下文本不在视野
- 影响：month/quarter/year 三个视图都异常（month 1020px、quarter 7462px、year 43800px）
- 修复（仅 demo 层，core 不动）：App.vue 引入 `DEMO_TARGET_COLUMN_WIDTHS`（目标每列宽度）+ `DEMO_DAYS_PER_UNIT`（每月/季/年平均天数），`columnWidths` 由两者相除得到"每天像素"
- 默认值：day 30 / week 72 / month 34 / quarter 82 / year 120（每列像素）
- 注意：core 的 `defaultConfig.columnWidth = 30` 在 month 视图下也会得到 30 × 30 = 900px/月，同样是 bug，但当前未被触发（因为 demo 用了 columnWidths 覆盖）

### 列宽自适应屏幕（修复"挤一坨"）

- 用户反馈：100 条数据 + month/quarter 视图下，甘特条全挤在左侧，timeline 大部分空白
- 数据特点：100 条跨度 ~36 天、1000 条 ~60 天、3200+ 条 ~72 天（`createLargeDataset` 的 `group % 40` 限制了跨度上限）
- 解决： playground 层加自适应逻辑 `applyAdaptiveColumnWidth()`，根据 `spanDays` + `viewportWidth` 动态算 columnWidth
- 核心公式：`columnWidth = max(lowerBound, min(ideal, range.max))`
  - `lowerBound = max(range.min, viewportWidth / spanDays)` —— 至少填满视口
  - `ideal = 1.2 × viewportWidth / spanDays` —— 目标 1.2 倍视口留滚动余地
  - `range` = 每个 viewMode 的"每天像素" min/max（month 0.6-30、quarter 0.2-10、year 0.05-2.5、day 22-60、week 4-20）
- 触发时机：useDemoDataset / setDemoViewMode / window resize（debounce 150ms）/ onMounted 初始化
- 视口宽度测量：优先 `document.querySelector(".gantt-demo-hero .gantt-timeline").clientWidth`，fallback 用 window 估算
- 实现位置：playground/src/App.vue，demoColumnWidths 对象按 viewMode 动态更新，通过替换 columnWidths 引用触发响应式
- 验证：core 7 tests + vue-gantt 50 tests 全过
